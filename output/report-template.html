🔒 Security

FactorFindingImpact
Scoring method: Starts at 10.0. Each security finding deducts points based on severity (Critical: −2.0 to −3.0, High: −1.0 to −2.0, Medium: −0.5 to −1.0, Low: −0.25). Minimum score is 0.
📝 Code Quality
▼
FactorFindingImpact
Scoring method: Starts at 10.0. Deductions for missing tests (−1.0 to −3.0 based on coverage gap), code smells (−0.25 to −1.0 each), large files (−0.5 each), and poor error handling (−0.5 to −1.0).
🏗️ Architecture
▼
FactorFindingImpact
Scoring method: Starts at 10.0. Deductions for circular dependencies (−1.0 to −2.0), missing layered structure (−1.5), tight coupling (−0.5 to −1.5), inconsistent framework versions (−0.5), and excessive dependency count (−0.5).
⚙️ DevOps
▼
FactorFindingImpact
Scoring method: Starts at 10.0. Missing CI/CD: −3.0. Missing tests in CI: −1.5. No security scanning: −1.5. Missing lock file: −1.0. Missing README: −0.5. Missing LICENSE: −0.5. No Docker pinning: −0.5. Each missing governance file: −0.25.
📦 Dependency Risk

FactorFindingImpact
